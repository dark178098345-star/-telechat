# tele.chat Android

Нативная Android WebView-оболочка для живого сайта tele.chat.

- Android 7.0 (API 24) и новее.
- Загрузка фото и видео через системный выбор файлов.
- Голосовые сообщения с разрешением на микрофон.
- Внешние ссылки открываются в браузере.

Сборка выполняется GitHub Actions из папки `android-app`.
