# Обновление tele.chat V115 — истории

- Добавлена компактная лента историй над списком чатов.
- Историю можно создать из фото или видео до 60 секунд.
- К истории добавляется подпись до 180 символов.
- История автоматически исчезает через 24 часа.
- Для каждой истории доступны кольцо непросмотренной истории и просмотрщик с переключением.
- Владелец истории видит список зрителей, их аватарки и время просмотра.
- Для медиа добавлено отдельное хранилище Supabase `story-media`.
- Добавлена адаптация ленты и просмотрщика под телефон.

Для включения синхронизации между аккаунтами один раз выполни `supabase-stories-v115.sql` в Supabase SQL Editor.
