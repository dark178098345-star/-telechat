# Обновления Windows — v204 / оболочка 1.4.4

Сообщение о новой версии и «Обновить», ручная проверка в настройках. Проверка после запуска и раз в час при активном окне. Без автоматического скачивания или установки: нужен клик. «Позже» скрывает предложение этой версии на 24 часа. Сайт/телефон не показывают установку Windows.

Публикация: собрать 1.4.4 → проверить ASAR → опубликовать неизменяемый установщик через `scripts/publish-desktop.cjs` → сверить SHA-256/размер и полную загрузку через Electron → добавить эти точные данные в `desktop-update.json` → опубликовать веб-интерфейс и указатель. Нельзя заменять EXE под старым номером версии. Указатель обновления не кэшируется и не имеет offline-подстановки. Проверочный 1.4.3 отозван до публикации указателя: реальная загрузка выявила несовместимость `net.fetch` с ручным получением redirect-ответа. В 1.4.4 цепочка сначала проверяется штатным `net.request`/HEAD с синхронным `followRedirect`, затем `net.fetch` получает конечный файл без разрешения новых переходов.

Новая оболочка сама получает указатель с фиксированного HTTPS-адреса, не доверяет URL/хэшу из страницы, проверяет версию, точный путь release asset, размер, SHA-256 и MZ. Ограничены размер, разрешённые серверы перенаправлений и время загрузки. Повторный клик не запускает вторую установку. При ошибке до установки приложение остаётся открытым, частичный файл удаляется; доступен повтор.

Помощник — отдельный системный PowerShell, а не запускаемый из заменяемой папки Electron. Проверяет хэш перед подтверждением готовности и перед запуском, ждёт одобрения основного процесса и его завершения, не убивает зависшее приложение, запускает NSIS `/S --updated /D=...`, проверяет код выхода и перезапускает приложение. Нет отключения UAC, SmartScreen или политики выполнения скриптов. Системные ограничения могут требовать подтверждения/мешать установке. Результат неудачной установки сохраняется локально и отображается при следующем запуске новой оболочки.

Для 1.3.4–1.4.2 остаётся прежний preload API: веб-интерфейс передаёт ему уже проверенные сведения и обязательный SHA-256. В установщике есть ограниченная миграция: перезапуск после legacy `/S` без `--updated`, поскольку прежний помощник мог закрываться установщиком вместе со старым Electron. Совсем старым версиям без API и portable потребуется однократная обычная установка. Приложения, уже открытые на старом HTML, получат новый интерфейс после обновления страницы/следующего запуска.

Идентификатор `chat.tele.desktop`, NSIS GUID по этому идентификатору и каталог `appData/telechat-desktop` не меняются. База, аккаунты, файлы и пользовательские данные не удаляются. Сам установщик не подписан: SHA-256 — проверка целостности, не замена Authenticode и не защита от компрометации издателя/GitHub.

Проверки: модель/загрузка/ошибки/готовность помощника, IPC-изоляция, интерфейс с новым и старым API, браузер без установки, PowerShell-парсер, сборка NSIS, равенство упакованного исходника, публичный SHA-256 и указатель. Фактическая установка поверх активной пользовательской установки не выполняется; системные запросы не подтверждаются автоматически.
