# ExstraChat Desktop

Windows-оболочка для `https://dark178098345-star.github.io/-telechat/`.

- `pnpm start` — запуск в режиме разработки.
- `pnpm dist` — сборка установщика и portable EXE в папку `dist`.

Приложение требует интернет для работы с Supabase. Сборка без цифровой подписи может вызвать предупреждение Windows SmartScreen.

После переименования сохранены `appId=chat.tele.desktop` и каталог данных `telechat-desktop` — вход, локальная музыка и настройки не мигрируют и не удаляются.
