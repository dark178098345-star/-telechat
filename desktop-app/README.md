# ExstraChat Desktop

Windows-оболочка для `https://dark178098345-star.github.io/-telechat/`.

- `pnpm start` — запуск в режиме разработки.
- `pnpm dist` — сборка установщика и portable EXE в папку `dist`.

Приложение требует интернет для работы с Supabase. Сборка без цифровой подписи может вызвать предупреждение Windows SmartScreen.

После переименования сохранены `appId=chat.tele.desktop` и каталог данных `telechat-desktop` — вход, локальная музыка и настройки не мигрируют и не удаляются.

## 1.4.0 — Сайты

Раздел открывается из бокового меню. По умолчанию он находится внутри основного окна; кнопка «Отдельное окно» переносит те же страницы в своё окно, а «В раздел» возвращает их без загрузки заново. Возврат в чаты скрывает раздел, сохраняя вкладки. Закрытие отдельного окна уничтожает его страницы. До восьми вкладок; новые всплывающие страницы требуют явного подтверждения.

Содержимое сайтов работает без preload/Node.js в отдельной постоянной сессии `persist:exstra-sites-v202`, не в сессии чата. Камера, микрофон, геолокация, захват экрана, устройства, уведомления и скачивания запрещены. Для несовместимого сайта есть «Открыть в обычном браузере». Полноценной замены Chrome, менеджера паролей и DRM-поддержки не обещается.

Установщик `dist/ExstraChat-Setup-1.4.0.exe` рассчитан на обновление прежней установки, без смены appId и каталога пользовательских данных. Цифровая подпись не настроена; это явно сообщается при передаче сборки.

Для разработки: `EXSTRACHAT_DEV_USER_DATA` задаёт отдельный профиль только у незапакованного приложения; `--sites-preview` открывает тестовое окно сайтов. Эти флаги не дают установленной сборке менять расположение данных.
