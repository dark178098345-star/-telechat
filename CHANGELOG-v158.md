# tele.chat · v158 — цветные фигурки вокруг глазок

Добавлена цветная обводка по референсу: мягкая фигурка за пиксельными глазками. Для каждой эмоции есть свой цвет и силуэт: сиреневый цветок спокойствия, жёлтые фигурки радости и смеха, синяя капля грусти, розовое сердце любви, красная вспышка злости и другие варианты.

Форма меняется вместе с выражением глазок в чатах и демонстрациях. При смене эмоции есть короткое плавное появление. В настройках глазок добавлен отдельный переключатель «Цветная обводка»; отключение обводки сохраняет сами глазки и их реакции. Выбор сохраняется отдельно для аккаунтов на этом устройстве.

Глазки сохраняют пиксельную графику. Внешние файлы, библиотеки и изменения базы не нужны. Остальные части приложения не менялись.
