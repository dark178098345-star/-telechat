# v161 — ExstraChat

- tele.chat переименован в ExstraChat: загрузка, вход, меню, настройки, профили, уведомления, QR-карточка и PWA.
- Музыкальный раздел теперь ExstraMusic.
- Android 1.2.6: новое имя приложения и уведомлений, прежние applicationId и ключ подписи для обновления поверх установленной версии.
- Windows 1.3.4: новое имя окна, трея, ярлыка и установщика. Сохранены appId и каталог данных `telechat-desktop`; помощник обновления распознаёт новое и старое имя EXE.
- URL сайта, Supabase, имена внутренних API, ключи настроек и хранилищ не менялись. История сообщений и пользовательский контент не переименовываются.
- Старые релизы не удалялись. Исходники Windows-оболочки сохранены в `desktop-app` для дальнейших сборок.
