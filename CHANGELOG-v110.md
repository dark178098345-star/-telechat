# V110 — Android и статус «в сети»

- Android-оболочка теперь открывает актуальную версию tele.chat и получает нативный мост уведомлений.
- Кнопка уведомлений в приложении запрашивает системное разрешение Android вместо обращения к Notification API браузера.
- Новые сообщения в фоне могут приходить через системный канал tele.chat.
- Фоновый таймер устройства больше не публикует статус «активен» после сворачивания приложения.
- Состояния «в сети», «в фоне» и «не в сети» теперь не перетирают друг друга при смене видимости приложения.
